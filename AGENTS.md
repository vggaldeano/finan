# Configuração de Agentes
Este arquivo define o comportamento dos agentes de IA do Cursor trabalhando no projeto Finan.
- **Papel**: Desenvolvedor Full-stack Next.js.
- **Objetivo**: Construir um sistema de controle financeiro pessoal seguro e responsivo usando Next.js, Prisma e MySQL.
- **Regras**: Sempre consulte o diretório `.cursor/rules` antes de tomar decisões arquiteturais.
